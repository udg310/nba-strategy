# NBA 波段策略 · 定稿（2026-11-13）

> 代码：`scripts/strategy.py`（唯一策略）+ `scripts/nba_data.py`（纯数据）
> 数据：971 场（2023-24 / 2024-25 / 2025-26）；实盘 14 场（2026-11-12/13）
> 原则：**状态 → 信号 → 入场**；弱队侧过程出场，强队侧明确定义为结算。

## 1. 框架

| | A 弱队领先 | C 比分接近弱队起势 | D 末节强队锁胜 |
|---|---|---|---|
| 赛前过滤 | 强队 ≥0.60 | 无 | 强队 ≥0.60 |
| 状态 | `m_fav ≤ −5` | `−5 ≤ m_fav < 0` | **Q3 剩 6:00 起**（el ≥ 2040）且 `5 ≤ m_fav < 10` |
| 信号 | 120s 游戏时钟内 `m_fav` 再降 ≥3 | 同左 | 取首个状态时点 |
| 买入 | 弱队 | 弱队 | 强队 |
| 入场价 | 0.10 起，无上限 | 同左 | **0.70–0.80** |
| 出场 | TP+20c / 无止损 / Q4 6:00 | 同左 | **持有到终场结算** |
| 仓位 | 1.0× | 1.0× | 2.0× |

`m_fav` = 强队得分 − 弱队得分。主客只旋转符号，不参与任何规则。

### 不变量（代码断言）

- A/C 的出场原因只可能是 `target` / `force`，**没有结算路径**。
- D 的出场原因只可能是 `settle`，**没有止盈/止损/强平**。
- D 在首个状态时点价格不合格时，**放弃整场**，不等到便宜再进。实测"等到便宜"会让 2026 赛季从 +10.2% 掉到 +0.3%。
- 标签不可信的场次（4/971）由 `label_sane()` 强制排除。

### 2.3 实盘实测的真实交易成本（重要）

2026-11-13 在真实账户上做了 **4 次完整往返**（买入→卖出），对比"成交记录里的价格"和"USDC 余额的实际变化"：

| 入场价 | 价差成本 | 实际成本 | 超额 | `p(1−p)` | 超额占比 |
|---:|---:|---:|---:|---:|---:|
| 0.23 | 1.0c | 2.74c | 1.74c | 0.177 | 9.8% |
| 0.29 | 1.0c | 3.04c | 2.04c | 0.202 | 10.1% |
| 0.40 | 1.0c | 3.39c | 2.39c | 0.240 | 10.0% |
| 0.81 | 1.0c | 2.51c | 1.51c | 0.154 | 9.1% |

**交易所实际收取约 `0.10 × p × (1−p)` 的往返手续费**（四次测量 9.1%–10.1%，高度一致）。
成交记录里的 `fee_rate_bps` 字段显示 `0`，但 USDC 余额确实少了。

所以每边的真实成本是 **半价差 + 0.05×p(1−p)**，在 p=0.4 时约 **1.7c**，而旧模型假设 1c。
代码里是 `S.entry_cost(p)` / `S.exit_cost(p)`。

## 4. 结论与限制

**成立的部分**
- 弱队侧的错价是稳定的：A +8.8pp、C +7.7pp，两个赛季一致。
- D 的错价集中在"Q4 领先 5–10 且价格 ≤0.80"：+7.9pp，2025/2026 分别是 +10.5%/+10.2%。

**必须记住的限制**
1. **全部收益依赖 1c/边成交。** 实盘价差中位 1.0c，但深度未测。
2. **D 是结算（赌结果）**，不是过程交易，已单列为独立通道。
3. **D 的样本只有 61 笔**，95% 区间 [−2%, +21%] 仍含 0。
4. **A/C 有 18.5% 的单笔接近全损**，止损会让整体变差（A 从 +16.6% 降到 +10.7%）。
5. **单笔仓位 5%**：历史最长连亏 9 笔，5% 仓位下熬过之后剩 76% 本金。

**已否决、不要再测**
- 做多强队的动量类信号（起势、追分、翻盘）：四种状态全负，校准差 −0.1 到 −6.8pp。
- 价格下限版本（≥0.85 / ≥0.90）：−1.6% / −1.2%，拖累整体。
- 任何止损方案：固定/比例/时间止损全部让收益变差。
- 复利仓位：超过单笔容量后增长退化线性，且回测分红数字是幻觉。
